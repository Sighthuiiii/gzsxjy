# 高中数学讲义

高中数学系统化讲义，涵盖从初高中衔接到微积分的完整知识体系。

## 目录结构

- **Part I** — 初高中衔接（代数式、方程、初中几何回顾）
- **Part II** — 集合、逻辑与不等式
- **Part III** — 基本初等函数（函数概念、指对幂函数、三角函数）
- **Part IV** — 线性代数入门与代数基础（复数、域）
- **Part V** — 立体几何与线性代数初步
- **Part VI** — 解析几何
- **Part VII** — 数列
- **Part VIII** — 统计与概率
- **Part IX** — 微积分初步
- **Part X** — 初等数论
- **GaoKao** — 历年高考真题
- **tikz111** — TikZ 绘图源码
- **figures** — 插图资源
